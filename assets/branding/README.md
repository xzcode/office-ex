# Office EX application mark

Original project-owned geometric EX monogram, licensed under the repository MIT license. No typeface, external logo, stock icon or trademark artwork was copied. The dark blue rounded-square tile uses transparent outer pixels, a white E and a mint X.

`mark.json` is the single editable geometry source. `scripts/build-branding.mjs` creates the SVG, transparent PNGs, multi-resolution ICO and ICNS from that source without network access, platform font rendering or additional dependencies. Generated assets stay under dist and are included in native preview distributions, not checked in as binaries. The mark is a development-preview design; it has not received user visual approval or trademark clearance.
