## M7.1 A — XLSX rich text, named styles and chart references

- Admit ordinary rich shared strings and inline strings, with an explicit bounded run model (font family, size, color, bold, italic and underline), without changing scalar formula/clipboard semantics. Cell edits preserve unchanged grapheme-aligned prefix and suffix formatting; inserted text inherits the adjacent preceding run or first run at the start. Cell-level font changes apply to all runs. Copy/fill, clear, undo and native save respect the run model. Virtualized cells render only trusted model spans. Source-owned unchanged shared string nodes and native styles remain preserved; changed runs may materialize resolved theme colors/fonts rather than preserving original theme font tokens. Complex phonetic annotations, unsupported rich font attributes and arbitrary substring formatting tools remain outside this profile.
- Admit a bounded registry of ordinary visible custom named cell styles with direct font/fill/border/number-format components and fully materialized cell formatting. Preserve native xfId association through edits/copies; source style records are retained and new cell XFs appended with mapped original parent IDs. The Ribbon can apply an existing named style or reset to Normal. Source style definition editing, creating new named styles in the UI, named parent alignment and unsupported built-in/complex inheritance remain outside profile. New model fields are validated; legacy XLS conversion rejects unsupported rich/named semantics explicitly.
- Chart range/anchor positions now shift in the same transaction as row or column insertion/deletion. Same-sized local chart vectors remain aligned; destructive source vector or label removal and overflow fail explicitly rather than dropping a chart. New charts are placed below horizontally overlapping charts using existing approximate default grid geometry. Exact floating-object placement and more complex charts remain open.
- Evidence: TypeScript, architecture, 296/296 core tests, targeted XLSX 18/18, desktop build and dependency audit passed. Independent XlsxWriter/openpyxl shared/inline rich text, named association, formula-cache readback and chart range shift passed; added to npm test:interop. Native sandboxed Linux 3/3 [evidence](verification/m7/native-m7-sheets.json): display rich spans, edit retaining unchanged runs, apply named style and save/reopen.
