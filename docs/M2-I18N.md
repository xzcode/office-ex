2026-11-24。初始实现，未完成全部 I18N 规范；CI 结果以实际运行记录为准。
- 新增无外部依赖的 packages/i18n，类型化消息键、占位符检查、22 个目标 locale 注册表，当前开放四个完整候选界面资源：简体、繁体、英语、日语。其余 18 个 UI 目录未实现，不伪装支持。
