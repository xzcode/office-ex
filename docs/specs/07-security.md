# 07 桌面、保存与安全

UI-01 单主窗口、多文档标签、首页/最近文件、各编辑器工作区；主题 token 浅色/深色/系统，统一控件尺寸。M1 中文/英文 message key；M2-I18N 开始统一类型化键，首个正式版 22 个 locale、热切换、独立地区与文档语言及 RTL；语言包本地随应用分发，禁止在线翻译或远程字体，按 [I18N-01–05](09-i18n.md) 验收；Cmd/Ctrl 文件及撤销重做快捷键、键盘焦点和 IME 不冲突，可访问性。只读、警告与阻塞持久可见。异步任务进度、取消；关标签取消任务；同一文件多开检测冲突。
FS-01 文件权限仅来自用户选择/拖入/文件关联，主进程持有会话/窗口/操作绑定的有限 token，校验 IPC sender/schema/size/permission，禁止通用读写/shell/URL API。文件/设置/恢复均本地，最近记录可清除。
FS-02 保存检查 snapshot revision、能力报告、目标授权、原文件 identity/摘要或可靠外部修改检测；另存不默认覆盖，覆盖须确认。防符号链接/TOCTOU，临时文件同目录独占随机名，权限受限；写入完整→重读验证→flush/fsync→原子 replace，平台允许同步目录；失败保原件，不先删后写，网络盘无法保证时限制。保存中新增修改仍 dirty。跨格式转换不覆盖源。
FS-03 自动恢复默认脏内容每 30s 本地快照/增量日志；最近3份、单文档256MiB预算，超限提示。恢复为未保存副本，校验 schema/hash，用户选择恢复/放弃；成功保存只清理已覆盖版本。磁盘满、断电/进程退出、权限不足、取消/冲突回归。
SEC-01 Electron sandbox/contextIsolation/webSecurity true，nodeIntegration false；可信本地协议、CSP、拒绝外部连接/导航/窗口/权限；preload 最小 typed API；不得在 main 解析不可信文档。隔离 worker/renderer 不具任意文件系统、网络、shell 权限；默认零网络请求；安全更新版本及锁文件审查。
SEC-02 ZIP 限制实际解压量、路径规范化、重复项、CRC、截断、symlink；禁 DTD、外部/自定义实体、XInclude，禁止将原始 XML/HTML/SVG 作为可执行 UI；CFB 链循环、扇区重叠/越界、整数溢出/不安全偏移、记录长度/递归深度、压缩媒体超限必须拒绝。VBA、XLM、OLE、DDE、外链、文档脚本不执行、不自动访问。签名/加密文件保守只读/拒绝。
SEC-03 初始产品资源预算（非格式理论上限，变更需 ADR/实测）：原始文件100MiB，ZIP 10000项、单项64MiB、总解压512MiB、压缩比200:1；XML 单部件32MiB、深度128、100万节点；CFB 最多10000目录项、层级128、单流64MiB、累计读取/物化512MiB、按实际文件长度约束扇区链；二进制记录深度128、总记录100万；图像4000万像素、媒体累计128MiB；公式AST深度128、token8192、单任务100万步，超限诊断而非保存伪结果。边读取边限额、可取消；不得只信声明长度。压测锁定内存/CPU/超时策略。
验收：恶意 ZIP/XML/CFB、畸形 DOC/XLS/PPT 记录、宏外链、非法 IPC、路径攻击、零网络、写入故障、恢复及并发冲突。
