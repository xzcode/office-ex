# 04 Writer

WRT-01 Document→Section→Block(Paragraph/Table/PageBreak)；Paragraph→Run/Text/Tab/LineBreak/Image；空段有选择位置；表格 cell 含 blocks。P0 A4 默认、纸型/方向/边距、单栏、基本分节。显式分页与自动分页分离，自动分页不是源文件硬分页。
WRT-02 样式级联：文档默认→命名段落/字符样式→直接格式；支持字体、字号、粗斜下划线、颜色、对齐、缩进、行距、段前后；继承循环/缺失字体明确诊断，保留源字体名。使用统一 FontMetrics 测量及绘制，处理中英/emoji/grapheme、中文标点断行及 RTL；构造行/段/页盒，跨页段落及简单表格不裁剪；增量重排受影响页。复杂分栏/浮动对象/孤行规则不伪称支持。
WRT-03 IME、输入/选区替换、删除、分段合段、样式、复制粘贴、撤销/重做；命中测试共享布局快照。Run 拆分保留属性。P0 简单矩形表格的行列编辑、边框/宽度；内嵌 PNG/JPEG 与等比缩放；未知复杂表格、浮动图片、域/修订、页眉页脚等限制编辑或只读。
WRT-04 同模型支持 DOCX 和 DOC；格式差异能力预检，保留原始部件/流。打印/PDF 使用同一分页模型而非屏幕截图。
国际化：按 [I18N-04](09-i18n.md) 处理文档语言、段落/run 方向与 script 属性、CJK/RTL/复杂文字 shaping、逻辑与视觉选区、字体回退，DOC/DOCX 安全保留源标记和编码；不得用 UI locale 修改导入内容。
验收：Unicode/IME 提交与撤销；三页含显式分页、跨页段落、表格/图片；DOC/DOCX 各自新建、导入编辑、复开以及双向转换；检查段落文字、样式、行列、图像摘要、分页与参考 Office 视觉。
