# 08 质量、兼容性及交付

QA-01 C0未实现/拒绝；C1识别/安全只读；C2新建输出且独立读取；C3导入/编辑/原格式保存/复开，语义与安全保留；C4在 C3 基础上参考 Office 布局/计算/打印验证。按格式+版本+功能标记等级，不以单一兼容率宣传。六种格式 P0 编辑功能正式版必须 C3，分页/公式/幻灯片布局等具体核心功能还需 C4；PDF 依专门验收。早期内部构建可标未完成，不能冒充正式版。
QA-02 每个需求 ID 对应夹具、测试、结果、commit/date/platform/工具版本。状态 planned/implemented/verified/blocked；证据缺失不得 verified。独立读取工具验证语义，不代替 Office GUI。源样本合成或许可明确，记录生成版本和 SHA；用户文档不进仓库。
QA-03 每个 doc/docx/xls/xlsx/ppt/pptx：新建输出→Office 打开；Office 创建→导入→未改另存→完整性检查；指定编辑→原格式保存→Office 复开→语义与未知数据检查；新旧双向转换→复开→可表达功能检查；目标限制/未知内容/恶意损坏→诊断/阻止→原件 SHA 不变。旧版本范围明确记录来源与实际测试版本；不能用一份新 Office 输出声称所有旧应用实测通过。
QA-04 固定 OS、字体、版本、DPI/zoom、尺寸；页数/幻灯片数、文字不丢/不遮挡、关键几何原生精度（视觉目标边界≤2 CSS px at 96 dpi），固定字体分页夹具的页数和指定段落断行一致；字体替代显式诊断。公式按函数精度阈值，类型/引用/错误严格相等。保留原样流/part 哈希，不比较 ZIP/CFB 物理排列。
QA-05 初始性能预算（尚未测，M4 16GB或记录实际测试机，固定样本冷/热至少5次，报告中位数/最大值，交互p95）：冷启动≤3s；20页 DOC/DOCX 首屏≤2s、输入≤50ms；100k 非空 XLS/XLSX 打开≤5s、滚动帧≤33ms、1000关联格重算≤200ms；30页 PPT/PPTX 首屏≤3s、拖动帧≤33ms；单文档进程总 RSS 目标≤800MiB并记录峰值。无法满足先优化/说明阻塞，不静默降目标。
QA-06 数据损坏、安全漏洞、崩溃破坏原件、未授权访问、默认联网及 P0 缺失是正式版阻塞。CI 锁定依赖、类型检查、相关测试、可追溯产物；阶段不重复无关打包。Release 包含 native installer、源码 tag、SHA256、许可证/NOTICE、已验证格式矩阵、限制说明；平台逐个安装/启动/安全验证。

QA-07 国际化正式版验收：按 [I18N-01–05](09-i18n.md)，22 个目标 locale 必需键 100%、术语审查、地区/公式一致性、RTL/CJK/复杂文字输入与排版、六格式/PDF 文字保留以及三平台相关实测。语言切换不得更改文档或历史；未达 P0 则阻塞正式发布。

## 里程碑（重新冻结）
| 阶段 | 交付及退出门槛 |
|---|---|
| M0 | 自主选型、规范/追踪矩阵、OOXML spike；依赖锁定/桌面启动尚未完成。 |
| M1 | 安全 desktop shell、文件会话/事务、共享模型/能力、ZIP/XML/OPC 与 CFB 有界容器读写、安全保存和恢复；先验证基础容器，不假装支持所有格式。 |
| M2 | 先实施 M2-I18N 共用国际化层及 A 批；Writer 自研编辑及 DOCX 基本读写、Unicode/复杂文字布局；DOC 读写适配进入独立 M2-L 子阶段。 |
| M3 | Sheets 自研网格、公式计算及 XLSX 基本读写；BIFF8 XLS 读写适配 M3-L；地区格式/公式输入和 B 批语言接入。 |
| M4 | Slides 自研场景、PPTX 读写、PDF 工具；旧 PPT 读写适配 M4-L；完成 22 个 locale 全产品资源、复杂文字与 PDF 验证。 |
| M5 | 六格式双向转换、原格式往返、实际 Office 兼容/安全、性能、各平台打包。M2-L/M3-L/M4-L 全通过，且 QA-07/I18N-01–05 多语言 P0 验收全部通过才发布首个正式版。 |

旧格式子阶段可在共享 CFB 和各领域模型成熟后推进（优先 XLS→DOC→PPT），不要求为满足阶段名称而阻塞内部现代版研发。发布前不可跳过任何旧格式子阶段。严禁将规范本身、原型或结构检查冒充已实现功能。
