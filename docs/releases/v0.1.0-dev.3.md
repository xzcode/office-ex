# Office EX v0.1.0-dev.3 — M6 development-preview candidate

## Features since dev.2

- Word: native Table Grid, merged cells, section header/footer and page number fields, pagination controls and PDF layout improvements.

- PowerPoint: ordinary native table grid editing and object distribution, unified insert/edit controls and improved click/keyboard interactions.
