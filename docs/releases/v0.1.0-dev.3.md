# Office EX v0.1.0-dev.3 — M6 published development preview

## Features since dev.2

- Word: native Table Grid, merged cells, section header/footer and page number fields, pagination controls and PDF layout improvements.
- Excel: independent borders and default geometry, 48 registered functions, conditional numeric rules and three basic native chart types.
- PowerPoint: ordinary native table grid editing and object distribution, unified insert/edit controls and improved click/keyboard interactions.

- [x] Prepare separate version and audited lock with no third-party dependency changes.

- [x] Publish prerelease and confirm public assets. Never overwrite dev.2.

No claim of full Office fidelity or formal release. Unsupported complex document features remain protected. Windows signing and macOS notarization are not established. Human locale review, reference compatibility, performance and physical printing/IME acceptance remain open.
