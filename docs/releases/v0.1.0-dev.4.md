# Office EX 0.1.0-dev.4 — published development preview

Published after exact-source three-platform CI and installer verification.

Includes M7.1–M7.5: native sheet rich text and named styles, Writer page-story variants, PPTX merged tables and formatting, sparse calculations, improved file I/O, independent document windows, draggable titlebar, resizable panels, non-selectable UI labels, eight document file associations and targeted DOCX interoperability fixes.

The installer registers alternative handlers without forcing the system default. Office compatibility remains bounded. The specific user DOCX is not yet reproduced. Local check: 316/316; native Linux product 6/6 and quit 2/2; ordinary Office corpus and Chinese DOCX passed. Full local legacy interoperability is blocked by missing xlrd; native installer acceptance is pending CI.
