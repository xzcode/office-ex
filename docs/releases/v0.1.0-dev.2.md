# Office EX v0.1.0-dev.2 — development preview candidate

## What changed since the public dev.1

- Simplified Workbench V2: new native-format documents, recent files, recovery, and secondary legacy/draft formats.
- Original module marks, unified compact ribbon and editor chrome; native macOS titlebar integration with native traffic lights. Windows and Linux retain their native frame.
- Improved ordinary external Word, Excel and PowerPoint format profiles; unsupported modern files show a bounded read-only content preview with a diagnostic instead of only structural metadata. Originals are protected.
- Fixed immediate save after slide text editing. No new runtime dependencies.
